# BLOUNCER EDU — Ruang Kerja Guru

## Download / Install
BLOUNCER EDU is a web app that can be installed on supported phones and computers as a PWA.

After GitHub Pages deployment is complete, open the website link:
https://blouncercluper.github.io/BLOUNCER-EDU/

On Android (Chrome): open the link, tap ⋮, then choose **Install app** or **Tambahkan ke layar utama**.
On desktop Chrome/Edge: use the install icon in the address bar or browser menu.

## Deploy
GitHub Actions automatically deploys the contents when commits are pushed to `main`.
If this is the first deployment, ensure the repository's **Settings → Pages → Build and deployment → Source** is set to **GitHub Actions**.

## Data note
Student and teacher data is stored locally in the browser/device. It does not sync across devices. Export backups regularly from the app.
